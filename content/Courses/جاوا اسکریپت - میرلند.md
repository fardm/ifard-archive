## تعریف متغیر
```js
let country = "iran";
```

Variable (متغیر): country
Value (مقدار): iran

- کلمه اول متغیر با حرف کوچک شروع میشه کلمه دوم با حرف بزرگ: let firstName = "Ali"
  مگر اینکه از آندر لاین استفاده بشه: let first_name = "Ali"
- متغیری که همیشه ثابته همه حروف رو بزرگ می نویسند:
- let ADDRESS = "example.com"
