## جدول مارکدان عبارات رایج کامیت Git


| Type     | Description                                      | Example                                              |
| -------- | ------------------------------------------------ | ---------------------------------------------------- |
| feat     | New feature                                      | `feat: Add user authentication`                      |
| fix      | Bug fix                                          | `fix: Prevent crash when loading data`               |
| docs     | Documentation update                             | `docs: Update README with installation instructions` |
| style    | Code style changes (formatting, etc.)            | `style: Apply code formatting rules`                 |
| refactor | Code changes that don't add features or fix bugs | `refactor: Extract database connection logic`        |
| test     | Add or modify tests                              | `test: Add unit tests for user model`                |
| chore    | Maintenance tasks (updating dependencies, etc.)  | `chore: Update npm packages`                         |



تنظیم ادیتور ترمینال:
git config --global core.editor "'C:/Program Files/Notepad++/notepad++.exe'"
